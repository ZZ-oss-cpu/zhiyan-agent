## 九、总结

**答辩要反复讲的四件事**

1. **行级 bbox 锚点溯源**——不是"给出处"，而是"指到那一行的那个矩形"，含 OCR 扫描件同构复用。
2. **PageRank + 介数中心性双指标图谱 + 时间线剔旧 idea**——有学术算法味道，不是套壳 ECharts。
3. **语义去重 v1→v7 + 版本 Diff + HITL 决策**——正命中官方用例，是"人机协同"的正当示范。
4. **从读到写的闭环**——框架（无幻觉 References）、四格式拓扑图、四类可视化 + 自适应图注、中译英、整篇翻译导出，均有独立入口可演示。

**已达标（模块层面）**：模块一（除公式 LaTeX/附录/超长文档）、模块二、模块三（全）、模块四（主体）、模块五（主体）、模块六（全）。

**仍缺（决定上限）**：稀疏检索/重排、原生工具调用、Guardrails、公式 LaTeX、541 页性能、工程形态（单文件 + 501 接口）。
> 语义 Embedding 已于 2026-11-05 补齐（本地 ONNX 384 维，7650 块重建，中文直查英文 0.72–0.75），"检索质量"不再是空白项，剩下的增量在 BM25 融合与 rerank。

**一句话结论**：功能清单已经"齐"，现在拼的是**检索的确定性**与**工程的体面程度**——继续加新模块的边际收益，已经低于把 P0 两条做扎实。
