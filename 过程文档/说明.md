赛项介绍
全国高校 AI 大模型挑战赛是面向未来的创新型技术竞赛，旨在探索“大模型驱动，Agent 自主进化”的科研新范式。本赛项以“智领科研·意图驱动：基于大模型与 Agent 架构的全流程科研助手构建挑战赛”为核心主题，要求参赛选手突破传统文献管理工具与简单对话 Chatbot 的局限，深度融合大语言模型（LLM）的通用推理能力与 Agent 架构的自主交互能力，从 0 到 1 构建一款涵盖文献智能解析、抗幻觉问答、沉浸式对比翻译、自动文献检索推荐、引用图谱分析及学术写作辅助的全流程“科研助手 Agent”。

本赛项强调以下核心能力的考察：

1. 多模态与细粒度文档感知力（Document Parsing & Multi-Modal Processing）

考察 Agent 面对复杂学术 PDF（包含扫描件、双栏排版、复杂公式、图表、层级树及参考文献列表）时的非结构化数据提取与理解能力。Agent 需具备基于内容的语义级去重能力（如识别 arXiv 上同一论文的 v1 与 v7 演进版本），并精准提示用户版本管理策略。

2. 抗幻觉 RAG 与多文推理能力（Retrieval-Augmented Generation & Multi-Paper Reasoning）

针对学术场景对“确定性”与“严谨度”的极致要求，考察选手设计 RAG（检索增强生成）与 Traceability（源头溯源）机制的能力。Agent 需不仅能回答单篇论文中的细粒度超参数、硬件环境等细节，还需具备跨多篇论文（如 Transformer vs. BERT，GPT-1 到 GPT-3）的演进对比、架构差异分析与长上下文关联推理能力。

3. 自主工具调用与闭环探索能力（Tool Use & Environment Interaction）

Agent 不仅依靠模型内建知识，更需具备出色的“手脚”。考察选手对外部 API（如 arXiv / PubMed 接口、搜索引擎）、Python 代码执行环境及学术数据库的集成调用能力，实现从“给定论文名称/参考文献”自动下钻下载、最新领域论文定期抓取，到结合 GitHub 开源复现性及用户偏好的精准推荐闭环。

4. 图谱拓扑挖掘与学术洞察生成（Graph Mining & Horizon Scanning）

考察 Agent 针对特定方向批量文献（如 20 篇相关论文）的局域引用关系建构（Citation Network）、基于图论算法的核心基石节点挖掘、自动领域综述生成以及结合最新研究时间线的 Future Work 探索能力（能自动过滤已被后续论文解决的旧 idea）。

5. 学术 Copilot 与数据可视化渲染（Academic Copilot & Visual Agent）

考察 Agent 在辅助写作与数据处理上的综合输出质量。包括从 Idea 到无幻觉 References 论文框架生成、利用 TikZ / Graphviz / Mermaid / Matplotlib 自动绘制架构拓扑图，以及将原始 CSV 数据自动转化为符合学术规范的精美图表与自动提炼结论的 Figure Caption。

命题背景
1.时代背景
2026 年，大语言模型（LLM）与 AI Agent 技术彻底引发了全球科学研究范式的深度变革。随着 DeepResearch、o3/o4 系列推理模型在深度思考与学术探究上的全面突破，以及各种专用科研 Agent 框架的演进，“AI4S（AI for Science）”已从最初简单的文献摘要提取，跨越到了能够自主进行文献阅读、逻辑推理、假设提出、实验代码生成乃至论文草稿撰写的“AI 科学家助手”新阶段。

然而，面对真实科研场景中极其严谨的学术规范、密集的长文本上下文、复杂的双栏与公式排版，以及对“幻觉零容忍”的确定性要求，简单的通用 Chatbot 已远无法满足需求。构建能够深耕科研全流程、具备高可靠性与自主协同能力的科研助手 Agent，成为了当下大模型技术落地最前沿、最具挑战性的核心赛道。

2.产业与学术需求
产业界与前沿学术机构对人才的需求正在发生结构性迁移：单纯依赖传统检索工具或人工阅读整理文献的效率瓶颈日益凸显，能够深刻理解科研业务逻辑、善于利用大模型能力并具备 Agent 系统架构与工程落地能力的“AI 时代科研精英与 Agent 架构师”正成为刚需。

现实中的科研痛点极其明确：
a.信息过载与文献时效： 每天爆发式增长的海量论文（如 arXiv 日均更新数百篇），亟需智能化的自动检索、过滤、去重与高精度图谱搭建；

b.读写效率与学术严谨： 跨语言阅读、双向对齐翻译、细粒度数据提取以及消除模型幻觉，是科研工作者对“确定性”工具的迫切渴望；

c.创意落地与实践复现： 从数据可视化、架构图生成到寻找尚未被尝试的科研创新点（Idea Validation），需要能够深度整合代码环境与外部 API 的复合型 Agent。

3.教育意义
本赛项不仅是一场前沿技术的较量，更是高校人工智能应用、AI4S（AI for Science）教育、复杂系统工程实践与学术创新素养的深度实践载体。通过“以赛促学、以赛促练、以赛促创”，引导学生在具备学术严谨性与技术挑战性的真实科研场景中，实现从“AI 使用者”向“AI 架构者”的跨越。

与单纯考察常规代码编写或基础 Prompt 调优不同，本赛项更关注学生是否能在复杂科研需求下，依次完成从理解科研痛点、设计 Agent 系统架构、集成多模态与 RAG 工具链、优化抗幻觉策略，到最终交付可复现成果的完整工程闭环。其教育意义具体体现在：

• 重塑科研范式认知，培养 AI4S 前沿视野： 让学生尽早接触大模型驱动的科研新范式，掌握利用 Agent 进行文献挖掘、数据分析与创新点探索的方法，提升科研效率与洞察力。

• 深化系统工程能力，打破“黑盒”依赖： 避开简单 API 调用的浅层模式，倒逼学生深入理解 Task Planning（任务规划）、Memory（记忆管理）、Function Calling（工具调用）及 Multi-Agent 协同等底层架构设计，锻炼解决复杂系统的解耦与编排能力。

• 强化严谨科学态度，树立抗幻觉与学术伦理意识： 引导学生在面对大模型“幻觉”时，学会通过 Source Tracing（源头溯源）、Guardrails（安全防护）和逻辑验证机制确保生成结果的准确性与严谨性，培养负责任的 AI 开发与学术创新态度。

命题范围
1.总体范围
本赛项围绕真实的前沿学术研究与论文写作场景展开，要求参赛队伍设计并实现一款全栈式、具备自主规划与协同能力的科研助手 Agent 应用系统。

大赛不限定具体的后端开发语言或前端框架，但作品必须满足以下基本要求：

输入素材可审查： 系统能够稳定处理学术界标准的 PDF 论文、扫描件 PDF；

输出成果可验证： 解析结果、问答溯源、图谱节点、代码与绘图脚本生成、综述文本等均需具备确定性、可被交互验证且具备高复现性；

系统运行闭环： 作品需包含完整的前后端界面与 Agent 后端服务，能演示从文献导入到写作辅助的全流程闭环。

2.详细命题模块
参赛队构建的科研助手 Agent 系统需全面覆盖以下六大命题功能模块：

模块一：PDF 文件管理与细粒度解析
基础 CRUD 与语义去重： 支持单篇/批量 PDF 上传。Agent 需实现基于内容的语义级去重（如对比 1706.03762v1.pdf 与 1706.03762v7.pdf 两个不同版本的正文），提示用户并智能建议保留最新版本。

多模态细粒度解析： 支持高难度文本（扫描件图像 OCR、长篇书籍如《Understanding Deep Learning》）。需细粒度抽取并结构化呈现：标题、作者及机构信息、摘要、一/二/三级标题树、表格、图表、LaTeX 公式、参考文献及附录。

模块二：抗幻觉知识问答（RAG & 多文推理）
单篇论文精准问答： 基于 RAG 或其他技术回答细粒度问题（如作者与机构、超参数 β_1/β_2 设置、训练 GPU 型号与数量、特定任务 BLEU 分数比对、指定文献完整引用信息等），必须提供原文参考出处/位置锚点以消除模型幻觉。

多篇论文跨文献对比： 具备多文联合推理能力（如对比 BERT 与 Transformer Encoder 的承袭与抛弃关系、GPT-1/2/3 的参数量演化、LN 位置调整细节以及 Context Window 递增过程）。

模块三：版式感知阅读与双向联动翻译
智能引导与双向跳转： 原生渲染单双栏/公式/表格，提取标题树状导航；支持正文引用标记（如 [11]）与 References 参考文献条目之间的双向无损跳转。

中英对比与联动滚动： 支持局部划词/悬停翻译及整篇翻译（输出 Markdown/HTML 或保持原位排版的 PDF，代码与公式保留英文）。支持中英对比阅读模式，实现两侧页面拖动时的自动同步滚动。

模块四：论文自动检索、追踪与智能推荐
智能下钻下载： 给定论文名称或参考文献列表，调用搜索引擎/API 自动抓取入库；具备“引用含金量”筛选机制，自动剔除应付式引用。

arXiv 动态追踪与个性化推荐： 利用 Sickle 等工具定期刷新追踪 arXiv 最新论文，结合用户本地文献库计算相关性；优先推荐附带开源 GitHub 代码（易复现）的论文，提供推荐理由、点赞/踩互动及多用户推荐算法拓展。

模块五：局域引用图谱挖掘与学术综述生成
引用拓扑图谱与基石节点： 针对批量文献（如 20 篇），Agent 自动解析彼此引用关系，前端渲染可视化图谱；运用图论算法计算并挖掘“基石论文”与“边缘衍生论文”。

自动综述与前沿探索： 基于图谱自动生成领域简短综述；提取多篇论文的 Future Work 部分，结合时间线与最新进展，自动排除已被解决的旧 idea，提炼出真正具有探索价值的未来方向。

模块六：学术写作辅助与数据可视化 Copilot

无幻觉框架与拓扑图生成： 根据给定 idea 自动输出包含 Abstract、Introduction、Related Work 和真实无幻觉 References 的论文框架；生成 TikZ / Graphviz / Mermaid / Matplotlib 等架构拓扑图脚本。

数据可视化与学术图注提炼： 读取用户上传的原始 CSV 数据，自动生成精美表格/折线图/柱状图/三维雷达图，并自动提炼符合学术规范、能说明核心趋势结论的 Figure Caption。

学术翻译： 支持将中文论文摘要或全文一键精准翻译为符合学术规范的英文。

3.测试数据集与验证用例
为了保证赛事评审的客观性、可复现性与公平性，组委会在官方提供的 pdf/ 目录下预置了标准测试数据集。参赛选手构建的 Agent 系统需能够稳定通过以下典型测试用例的验证（参赛队亦可自行补充更多 PDF 论文以丰富系统的演示效果）：

3.1内容去重与版本演进验证用例
测试文件： 1706.03762v7.pdf 与 1706.03762v1.pdf（《Attention Is All You Need》在 arXiv 上发布的第一版与第七版）。

验证流程：

用户首先上传最新版的 1706.03762v7.pdf 入库；
用户随后上传较旧版本的 1706.03762v1.pdf；
Agent 预期行为： 系统需能基于文本语义内容（而非仅凭文件名）检测出知识库中已存在内容高度重合的论文，主动向用户发出去重预警；支持由用户选择“覆盖”或“保留”现有版本；高级表现应能智能提示用户“库中已有版本较更新，建议保留”，甚至能够自动对比并总结出两个版本之间的主要修订差异。

3.2多模态与长文档解析验证用例
标准矢量 PDF： 以 1706.03762v1.pdf 为代表，验证系统对标准双栏学术论文的文本、层次标题、嵌入式 LaTeX 公式及表格的精细化解析能力。

图像扫描版 PDF： 以 1706.03762v1_img.pdf 为代表，验证系统在缺乏原生文本层的情况下的 OCR 识别、图表提取与结构化还原能力。

超长篇幅书籍/教材： 以《Understanding Deep Learning》（UnderstandingDeepLearning_02_09_26_C.pdf，共 541 页）为代表，验证系统对百页以上大体量长文本的切块（Chunking）、索引构建、长上下文分级加载及内存/显存占用控制等工程鲁棒性。

3.3基础与自定义测试集
目录中的其他预置 PDF 可用于验证单篇/多篇 RAG 问答、双向联动阅读、引用图谱构建及学术写作辅助等通用功能。

4.3评分说明
a.综合加权计算： 各维度采用百分制评分，最终按各维度权重加权计算总分。

b.专家组独立评审： 评审专家组由高校 AI / AI4S 方向学者、大模型算法专家、全栈架构师及行业从业者组成。每件作品由不少于 3 位评审专家独立评分，取平均分。

c.决赛答辩机制： 决赛阶段将增加现场/线上答辩环节，答辩表现（含代码架构讲解、Prompt 审计记录与现场 Demo 演示）占决赛总分的 30%。

5.大赛奖项评定规则
每一项评分都会有专门的评审组进行打分，最终得分将根据各项评分的加权总和得出。评审组由专业设计师、AI技术专家和相关领域的学者组成，确保评审过程的专业性和权威性。

奖项比例调整机制：大赛主办方保留根据实际报名人数、选手晋级情况及评审工作实际需求，对各级别奖项预设比例进行适当调整的权利，以保障评审工作的公平性与合理性。
